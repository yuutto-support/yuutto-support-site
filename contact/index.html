反馈内容问题时，最好带这些

  • 出问题的页面地址；
  • 你看到的旧内容；
  • 当前实际情况或截图；
  • 设备和系统版本（如果和教程有关）。

账号、订单和服务状态

这些需要后台查询的问题，不适合在普通网页里处理。请从品牌主站进入当前客服渠道，并注意不要在公开页面提交密码、验证码等敏感信息。

如果你是在 GitHub 上查看这个站，也可以先到 Yuutto Help 项目仓库。需要反馈页面错误时，可从仓库里的 Issues 入口提交；账号、订单和服务状态仍请走品牌主站的客服渠道。
