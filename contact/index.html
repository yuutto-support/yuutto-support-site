优途加速器人工客服

账号、套餐、订单、密码重置和线路服务等需要后台查询的问题，直接联系优途人工客服。

打开优途官网联系客服

最快的两种联系客服方式

官网客服
打开优途官网，在页面中的客服入口进入人工客服。
Windows 客户端客服
Windows 客户端主页右上角有客服入口，可直接进入人工客服。

这些问题直接找客服

  • 购买后套餐长时间没有显示。
  • 账号无法通过已绑定手机号或邮箱自行重置密码。
  • 订单、付款、退款或账号权限需要后台查询。
  • 所有节点长期无法使用，需要确认线路或服务状态。

只是连接不上？

如果账号和套餐正常，只是出现一直连接中、连接后没网络或网速慢，可先看优途连接问题解决方法。
