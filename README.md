# Yuutto Help

Yuutto / 优途加速器品牌帮助站。

## 发布
GitHub Pages: `main` branch + `/ (root)`。

当前 canonical 与 sitemap 基于：
`https://yuutto-support.github.io/yuutto-support-site/`

如果之后绑定独立域名，需要全局替换 `BASE_URL` 对应地址，并重新提交 sitemap。

## 内容原则
- 可变化信息标注核验日期。
- Apple 端信息优先核对 App Store。
- Android / Windows 未公开的信息不猜版本号。
- 不做近似页面批量复制。
- 页面优先解决真实用户问题，再考虑关键词覆盖。
