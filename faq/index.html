几个最常见的问题

优途加速器官网是哪个？

官网是 https://youtujsq9.net/。优途加速器是中文名，Yuutto 是英文名。

第一次使用可以不登录吗？

可以。新用户可先使用游客模式体验，已有套餐的用户直接登录自己的账号。

一直连接中怎么办？

先换一个地区重新连接；如果仍不稳定，再进入定制模式手动换具体节点。全部节点都失败时可继续看连接问题解决方法。

Windows 提示网卡安装或加载失败怎么办？

从优途官网下载 Windows 安装版重新安装，再启动客户端连接。
