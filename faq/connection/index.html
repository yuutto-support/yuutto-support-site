常见问题

优途加速器连接不上、断网或速度慢怎么办

先判断故障发生在“连接之前”还是“连接之后”，再做对应检查。不要一开始就卸载软件，也不建议直接关闭系统防火墙。

连接按钮一直转圈先查原始网络与线路显示已连接却断网检查原始网络与防火墙只有部分应用打不开检查加速范围手机锁屏后断开检查后台和省电限制

一直显示连接中或节点连接失败

  1. 先断开优途，确认浏览器在不使用加速器时可以打开普通网站。如果原始网络本身不可用，优先处理 Wi-Fi 或移动数据。
  2. 重新打开优途，选择另一条节点连接；如果某条线路失败而其他线路可用，暂时避开该线路。
  3. 多个节点全部失败时，尝试切换 Wi-Fi 和移动网络，或重新启动客户端；同时检查账号、套餐是否正常。
  4. 如果连接过程中出现 VPN 权限提示，请检查是否已经授予；如安装有多个 VPN 或代理应用，先断开其他应用再测试。

显示已连接，但所有网站都打不开

用一个简单测试区分问题：断开优途时普通网页打不开，先检查当前 Wi-Fi／移动网络；断开时正常、连接后所有网页都打不开，再检查节点、系统 VPN 与防火墙设置。若只有一个应用异常，不必按“全设备断网”处理。

显示已连接只表示客户端报告了连接状态。请先尝试打开两个不同的普通网站：如果都无法访问，断开优途确认原始网络是否正常；如果断开后可以访问，再重新连接其他线路测试。如果只有一个服务打不开，请直接查看针对个别网站或 App 的排查方法。

Windows 用户如果连接后连普通网站也打不开，可到下方检查客户端防火墙访问权限。修改规则前先确认所安装程序来自优途官网，不要随意开放不认识的软件。

只有个别网站或应用打不开

如果只有个别网站或 App 不能打开，先确认其他网站是否正常，再比较浏览器与 App 的访问结果。Android 指定加速还需确认目标应用已被选中。完整排查见部分网站或 App 无法访问；ChatGPT 的专属错误提示可查看ChatGPT 问题指南。

Android 使用几分钟后自动断开

如果刚连接时正常，锁屏或切换到其他应用几分钟后就断开，可能是系统的后台运行或省电限制影响了 VPN 服务。先在手机设置中找到“应用”或“电池”，查看优途是否被限制后台活动；可按需要允许其后台运行。

不同品牌手机的菜单名称不一样。可以同时检查是否启用了激进的省电模式，但无需关闭整部手机的安全防护。调整后锁屏测试一段时间，确认是否改善；若仅某个系统版本反复断连，记录手机型号和系统版本后联系客服。

Windows 网卡驱动与防火墙

提示网卡安装失败或加载失败

先退出客户端，重新从官网获取 Windows 安装版并按安装程序提示完成安装。绿色版应先完整解压后运行，不要直接在压缩包里启动。如果驱动问题持续存在，先记录错误提示，再联系客服，避免反复安装不明驱动。

连接后断网，检查 Windows 防火墙访问权限

  1. 确认优途下载来源可信且程序名称正确。
  2. 在 Windows 搜索中输入“允许应用通过 Windows 防火墙”（不同系统菜单名称略有差异）。
  3. 在允许的应用列表中查找当前安装的优途程序；如确有权限被阻止，在确认程序身份后按需允许通信。
  4. 保存后重新连接并测试。如果列表中没有程序或系统权限受管理策略控制，不建议用关闭整个防火墙来代替排查。

Windows 11 某些版本连接后无网络

如果使用 Windows 11 24H2，且完成节点、原始网络及防火墙检查后仍然无法联网，建议记录 Windows 版本、客户端版本与报错信息，联系产品客服确认是否存在对应版本的兼容性问题。不要自行启用或关闭不熟悉的 Windows 虚拟化组件。

能连接，但速度明显变慢

先用同一设备、同一网络、相同下载或网页场景做对比，再试另一条线路。节点延迟只是一个参考指标，并不等于实际下载速度；如果仅视频缓冲而普通网页正常，请转到视频播放问题。如果未连接加速器时同样很慢，应优先检查原始网络。

联系客服前准备：设备型号、操作系统版本、客户端版本、报错文字、出现问题的节点和已经尝试过的步骤。不需要提供账号密码、验证码或付款卡信息。查看客服入口。
