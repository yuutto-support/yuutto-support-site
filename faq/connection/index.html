优途加速器连接不上、无网络或网速慢怎么办

大多数连接问题先从换节点和切换加速模式处理；Windows 出现网卡驱动错误时直接使用安装版重新安装。

一直连接中或节点连接失败

  1. 切换另一个地区或节点重新连接。
  2. 如果只是一条线路失败，直接使用其他可用线路。
  3. 所有节点都失败时，换 Wi-Fi / 移动网络再试一次。

连接成功但没有网络或网速慢

  1. 先换其他地区节点，判断是否只是当前线路速度慢。
  2. 只有部分软件或网站打不开时，关闭“智能加速”切换到全局加速再试。
  3. 需要手动避开某条线路时，进入定制模式选择其他具体节点。

如果你想先了解智能模式、定制模式以及全局加速分别是什么，可看优途加速器使用指南。

Windows 提示网卡安装或加载失败

这表示网络代理驱动没有正确安装。到优途官网下载 Windows 安装版重新安装，再启动客户端连接。

显示已连接但还是不能用

客户端开始显示连接时间，或手机顶部出现 VPN / 钥匙图标，只能说明连接已经建立。如果目标网站仍打不开，优先换节点；只有部分应用受影响时再切换全局加速。
